# Mi Producto - Landing Page

Landing page estática para promocionar "Mi Producto" con diseño moderno y responsivo.

## 🚀 Características

- HTML5 semántico
- CSS moderno con variables y Grid/Flexbox
- Diseño totalmente responsivo
- Secciones: Hero, Features, Benefits, Contact
- Formulario de contacto
- Navegación sticky

## 📁 Estructura del Proyecto

```
/workspace/
├── index.html          # Página principal
├── css/
│   └── styles.css     # Estilos CSS
└── README.md          # Este archivo
```

## 🌐 Cómo Visualizar el Sitio

### Opción 1: Abrir directamente
Abre el archivo `index.html` en tu navegador favorito:
- Haz doble clic en `index.html`, o
- Click derecho → Abrir con → Navegador

### Opción 2: Servidor local simple
Usa un servidor HTTP local para mejor experiencia:

```bash
# Python 3
python3 -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js (si tienes npx)
npx serve

# PHP
php -S localhost:8000
```

Luego abre `http://localhost:8000` en tu navegador.
