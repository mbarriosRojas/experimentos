# Landing Mi Producto

A modern, responsive static landing page built with HTML5 and pure CSS.

## Project Overview

This is a static landing page showcasing a product with three main sections:
- **Hero Section:** Main visual presentation with call-to-action
- **Features Section:** Product highlights and key benefits
- **Contact Section:** Contact form for user engagement

## Technology Stack

- **HTML5:** Semantic markup for structure
- **CSS3:** Pure CSS (no frameworks or preprocessors)
- **No JavaScript:** Static, lightweight, and fast-loading
