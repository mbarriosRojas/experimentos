# Utils Directory

This directory contains utility functions and helpers.

## Files to be created:
- `generateToken.js` - JWT token generation utility
- `asyncHandler.js` - Wrapper for async route handlers

## Utility Functions

### generateToken.js
- `generateToken(id)` - Generate JWT token for user ID

### asyncHandler.js
- `asyncHandler(fn)` - Wrapper to handle async errors in Express routes
